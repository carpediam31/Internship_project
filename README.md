🎮 Tic Tac Toe Game

A fully responsive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project offers a smooth and interactive user experience with attractive colors and a clean layout.

✨ Features:

    Responsive design – works seamlessly on all devices.

    Two-player mode with real-time win detection.

    Stylish UI with vibrant colors and smooth transitions.

    Reset option to start a new match instantly.

    Simple and beginner-friendly JavaScript logic.

💡 Perfect for practicing DOM manipulation, event handling, and CSS animations.
Enjoy the fun of classic Tic Tac Toe with a modern, colorful twist!
